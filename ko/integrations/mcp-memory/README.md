# MCP Memory 연동

> MCP(Model Context Protocol)를 활용해 어떤 에이전트에든 세션을 넘나드는 영속 메모리를 부여합니다.

## 무엇을 해주나요

기본적으로 The Agency의 에이전트들은 매 세션을 맨땅에서 시작합니다. 컨텍스트는 에이전트와 세션 사이를 복사·붙여넣기로 수동 전달해야 합니다. MCP 메모리 서버는 이 점을 바꿔 줍니다.

- **세션 간 메모리**: 에이전트가 이전 세션의 의사결정, 산출물, 컨텍스트를 기억합니다
- **인계 연속성**: 한 에이전트가 다른 에이전트에게 작업을 넘길 때, 받는 쪽이 무엇을 했는지 정확히 recall할 수 있습니다 — 복사·붙여넣기가 필요 없습니다
- **실패 시 롤백**: QA 검증이 실패하거나 아키텍처 결정이 잘못된 것으로 드러났을 때, 처음부터 다시 시작하는 대신 정상 동작이 확인된 상태로 되돌립니다

## 설정

`remember`, `recall`, `rollback`, `search` 메모리 도구를 제공하는 MCP 서버가 필요합니다. 사용하는 MCP 클라이언트(Claude Code, Cursor 등) 설정에 추가하세요.

```json
{
  "mcpServers": {
    "memory": {
      "command": "your-mcp-memory-server",
      "args": []
    }
  }
}
```

`remember`, `recall`, `rollback`, `search` 도구를 노출하는 MCP 서버라면 어떤 것이든 동작합니다. 사용 가능한 구현체는 [MCP 생태계](https://modelcontextprotocol.io)에서 확인하세요.

## 어떤 에이전트에든 메모리를 추가하는 방법

기존 에이전트에 영속 메모리를 더하려면 에이전트 프롬프트에 **Memory Integration** 섹션을 추가하세요. 이 섹션은 에이전트가 중요한 시점에 MCP 메모리 도구를 사용하도록 지시합니다.

### 패턴

```markdown
## Memory Integration

세션을 시작할 때:
- 자신의 역할과 현재 프로젝트를 검색어로 삼아 이전 세션의 관련 컨텍스트를 recall하세요
- 자신의 에이전트 이름으로 태그된 메모리를 검토해 중단했던 지점부터 이어가세요

중요한 의사결정을 내리거나 산출물을 완성했을 때:
- 설명적인 태그(에이전트 이름, 프로젝트, 주제)를 붙여 그 결정이나 산출물을 remember하세요
- 미래의 세션이나 다른 에이전트가 무엇을 왜 했는지 이해할 수 있을 만큼 충분한 컨텍스트를 담으세요

다른 에이전트에게 인계할 때:
- 받는 에이전트를 대상으로 태그를 붙여 자신의 산출물을 remember하세요
- 인계 메타데이터를 함께 담으세요. 무엇을 완료했는지, 무엇이 남았는지, 다음 에이전트가 알아야 할 것은 무엇인지

무언가 실패해서 복구가 필요할 때:
- 마지막으로 정상 동작이 확인된 상태를 search하세요
- 처음부터 다시 만들지 말고 rollback으로 그 지점으로 복원하세요
```

### 에이전트는 이 지시로 무엇을 하나요

이 지침을 받은 LLM은 MCP 메모리 도구를 알아서 사용합니다.

- `remember` — 의사결정, 산출물, 컨텍스트 스냅샷을 태그와 함께 저장합니다
- `recall` — 키워드, 태그, 의미적 유사도로 관련 메모리를 검색합니다
- `rollback` — 문제가 생겼을 때 이전 상태로 되돌립니다
- `search` — 여러 세션과 에이전트에 걸쳐 특정 메모리를 찾습니다

에이전트 파일의 코드를 바꿀 필요도, API 호출을 작성할 필요도 없습니다. MCP 도구가 전부 처리합니다.

## 팁

- **태그를 일관되게 쓰세요**: 모든 메모리에 에이전트 이름과 프로젝트 이름을 태그로 붙이세요. 그래야 recall이 안정적으로 동작합니다.
- **무엇이 중요한지는 LLM이 판단하게 두세요**: 메모리 지침은 엄격한 규칙이 아니라 가이드입니다. 언제 remember하고 무엇을 recall할지는 LLM이 스스로 판단합니다.
- **롤백이 핵심 기능입니다**: Reality Checker가 산출물을 반려했을 때, 원래 에이전트는 변경 사항을 손으로 되돌리려 애쓰는 대신 마지막 체크포인트로 롤백할 수 있습니다.
