# 멀티 에이전트 워크플로: 랜딩 페이지 스프린트

> 에이전트 4명으로 전환율에 최적화된 랜딩 페이지를 하루 안에 출시합니다.

## 상황

신규 제품 출시용 랜딩 페이지가 필요합니다. 보기에도 좋아야 하고, 방문자를 전환시켜야 하며, 퇴근 전까지 라이브로 올라가야 합니다.

## 에이전트 팀

| 에이전트 | 이 워크플로에서의 역할 |
|-------|---------------------|
| Content Creator | 카피 작성 |
| UI Designer | 레이아웃과 컴포넌트 스펙 설계 |
| Frontend Developer | 구현 |
| Growth Hacker | 전환율 최적화 |

## 워크플로

### 오전: 카피 + 디자인 (병렬)

**1a단계 — Content Creator 활성화**

```
Content Creator를 활성화해 주세요.

"FlowSync"의 랜딩 페이지 카피를 작성해 주세요. FlowSync는 어떤 두 SaaS 도구든
5분 안에 연결해 주는 API 통합 플랫폼입니다.

타깃 고객: 중견 기업의 개발자와 테크니컬 PM.
톤: 자신감 있고, 간결하며, 약간 장난스럽게.

필요한 섹션:
1. 히어로 (헤드라인 + 서브헤드라인 + CTA)
2. 문제 제기 (페인 포인트 3가지)
3. 작동 방식 (3단계)
4. 소셜 프루프 (고객 후기 자리표시자 포맷)
5. 가격 (3개 티어: Free, Pro, Enterprise)
6. 마지막 CTA

훑어보기 쉽게 작성해 주세요. 군더더기는 넣지 마세요.
```

**1b단계 — UI Designer 활성화 (병렬 진행)**

```
UI Designer를 활성화해 주세요.

SaaS 랜딩 페이지의 디자인 스펙을 만들어 주세요. 제품: FlowSync (API 통합 플랫폼).
스타일: 깔끔하고 모던하며, 다크 모드 옵션 포함. Linear나 Vercel 같은 미감으로.

산출물:
1. 레이아웃 와이어프레임 (섹션 순서 + 여백)
2. 컬러 팔레트 (primary, secondary, accent, background)
3. 타이포그래피 (폰트 조합, 헤딩 크기, 본문 크기)
4. 컴포넌트 스펙: 히어로 섹션, 기능 카드, 가격 테이블, CTA 버튼
5. 반응형 브레이크포인트 (모바일, 태블릿, 데스크톱)
```

### 정오: 구현

**2단계 — Frontend Developer 활성화**

```
Frontend Developer를 활성화해 주세요.

다음 스펙으로 랜딩 페이지를 구현해 주세요:

카피: [Content Creator 결과물 붙여넣기]
디자인: [UI Designer 결과물 붙여넣기]

스택: HTML, Tailwind CSS, 최소한의 바닐라 JS (프레임워크 불필요).
요구사항:
- 반응형 (모바일 우선)
- 빠른 속도 (무거운 에셋 금지, 시스템 폰트 사용 가능)
- 접근성 준수 (올바른 헤딩 구조, alt 텍스트, 포커스 상태)
- 동작하는 이메일 가입 폼 포함 (action URL: /api/subscribe)

바로 배포할 수 있는 index.html 단일 파일로 전달해 주세요.
```

### 오후: 최적화

**3단계 — Growth Hacker 활성화**

```
Growth Hacker를 활성화해 주세요.

이 랜딩 페이지를 전환율 최적화 관점에서 검토해 주세요:

[HTML을 붙여넣거나 현재 페이지를 설명]

평가 항목:
1. CTA가 스크롤 없이 보이는 영역에 있는가?
2. 가치 제안이 5초 안에 명확하게 전달되는가?
3. 가입 플로에 마찰 구간이 있는가?
4. 가장 먼저 돌려볼 A/B 테스트는 무엇인가?
5. SEO 기본: 메타 태그, OG 태그, 구조화 데이터

일반론이 아니라 구체적인 변경안을 제시해 주세요.
```

## 핵심 패턴

1. **병렬 착수**: 카피와 디자인은 서로 독립적이므로 동시에 진행합니다
2. **병합 지점**: Frontend Developer는 두 결과물이 모두 나와야 시작할 수 있습니다
3. **피드백 루프**: Growth Hacker가 검토하고, Frontend Developer가 변경을 반영합니다
4. **타임박스**: 각 단계에 명확한 시간 제한을 둬서 범위가 번지는 것을 막습니다
