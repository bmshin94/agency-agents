# 예시

이 디렉토리에는 에이전시의 에이전트들을 함께 오케스트레이션해 실제 업무를 처리하는 모습을 보여주는 예시 산출물이 담겨 있습니다.

## 이 디렉토리가 존재하는 이유

agency-agents 리포지토리는 엔지니어링, 디자인, 마케팅, 제품, 지원, 공간 컴퓨팅, 프로젝트 관리 전반에 걸쳐 수십 개의 전문 에이전트를 정의합니다. 하지만 에이전트 정의만으로는 하나의 미션에 **모든 에이전트를 한꺼번에 투입**했을 때 어떤 일이 벌어지는지 알 수 없습니다.

이 예시들은 다음 질문에 답합니다. *"에이전시 전체가 협업하면 실제로 어떤 모습일까?"*

## 목차

### [nexus-spatial-discovery.md](./nexus-spatial-discovery.md)

**내용:** 8개 에이전트가 병렬로 작업해 소프트웨어 기회를 평가하고 하나의 통합 계획을 만들어 낸 완전한 제품 디스커버리 실습입니다.

**시나리오:** 웹 리서치를 통해 AI 에이전트 오케스트레이션과 공간 컴퓨팅이 만나는 지점에서 기회를 발견했습니다. 이후 에이전시 전체를 동시에 투입해 다음 산출물을 만들었습니다.

- 시장 검증 및 경쟁 분석
- 기술 아키텍처(전체 SQL 스키마를 포함한 8개 서비스 시스템 설계)
- 브랜드 전략 및 비주얼 아이덴티티
- 시장 진입(GTM) 및 성장 계획
- 고객 지원 운영 청사진
- 페르소나와 여정 지도를 포함한 UX 리서치 계획
- 65개 스프린트 티켓으로 구성된 35주 프로젝트 실행 계획
- 공간 인터페이스 아키텍처 명세

**투입된 에이전트:**
| 에이전트 | 역할 |
|-------|------|
| Product Trend Researcher | 시장 검증, 경쟁 환경 분석 |
| Backend Architect | 시스템 아키텍처, 데이터 모델, API 설계 |
| Brand Guardian | 포지셔닝, 비주얼 아이덴티티, 네이밍 |
| Growth Hacker | GTM 전략, 가격 정책, 출시 계획 |
| Support Responder | 지원 등급, 온보딩, 커뮤니티 |
| UX Researcher | 페르소나, 여정 지도, 디자인 원칙 |
| Project Shepherd | 단계별 계획, 스프린트, 리스크 등록부 |
| XR Interface Architect | 공간 UI 명세 |

**핵심 시사점:** 8개 에이전트가 모두 병렬로 실행되면서도 조정 비용 없이 서로를 교차 참조하는 일관된 계획을 만들어 냈습니다. 이 산출물은 "기회를 찾아라"에서 "여기 전체 청사진이 있다"까지 한 세션 안에 도달하는 에이전시의 역량을 보여줍니다.

## 새 예시 추가하기

흥미로운 멀티 에이전트 실습을 진행했다면 여기에 추가해 보세요. 좋은 예시는 다음을 보여줍니다.

- 공동의 목표를 위해 협업하는 여러 에이전트
- 에이전시 역량의 폭
- 에이전트 정의의 실제 적용 가능성
