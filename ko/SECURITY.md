# 보안 정책

## 취약점 신고

이 프로젝트에서 보안 취약점을 발견하셨다면 책임감 있게 신고해 주세요. 보안 취약점에 대해서는 공개 GitHub 이슈를 열지 **마세요**. GitHub Security 탭을 통해 비공개 보안 권고(private security advisory)를 열어 주세요.

## 대응 일정

- 접수 확인: 48시간 이내
- 1차 평가: 7일 이내
- 수정 또는 완화 조치: 심각도에 따라 다름

## 범위

이 리포지토리는 마크다운 기반의 에이전트 정의와 설치·변환용 셸 스크립트로 구성되어 있습니다.

### 에이전트 파일 (.md)
- 실행되지 않는 프롬프트 정의입니다
- 에이전트 파일에는 API 키, 비밀값, 자격 증명을 저장하면 안 됩니다

### 셸 스크립트 (scripts/)
- install.sh, convert.sh, lint-agents.sh는 실행 파일입니다
- 기여자는 실행 전에 스크립트에 의도하지 않은 동작이 없는지 검토해야 합니다

## 기여자를 위한 베스트 프랙티스

- API 키, 토큰, 자격 증명은 절대 커밋하지 마세요
- 에이전트 마크다운 파일 안에 실행 가능한 코드를 추가하지 마세요
- 셸 스크립트는 머지 전에 반드시 검토해야 합니다
- 프롬프트 인젝션을 시도하는 의심스러운 에이전트 정의는 신고해 주세요
